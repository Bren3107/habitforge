# HabitForge

AI-powered habit formation app. Guides users through a 4-question onboarding conversation, generates a personalised multi-week habit plan using psychology principles, and tracks progress with a gamification dashboard.

## Demo user flow

1. `/onboard` — 4-question AI conversation (Claude Haiku)
2. `/results` — personalised habit plan generated by Claude Sonnet, showing confidence score and psychology principles used
3. `/dashboard` — daily check-ins, XP, streaks, badges, and 28-day progress chart
4. `/evaluation` — synthetic evaluation tool: runs 9 personas through the full pipeline and reports personalization, principle coverage, confidence, and difficulty-appropriateness scores

## Tech stack

| Layer | Choice |
|---|---|
| Framework | Next.js 16, App Router, React 19, TypeScript |
| Styling | Tailwind CSS 4 (forge dark theme) |
| AI | Anthropic Claude — Haiku (questions) + Sonnet (plan generation) |
| Database | Supabase (PostgreSQL + pgvector) |
| Animations | Framer Motion |
| Charts | Recharts |
| Testing | Jest + ts-jest |

## AI pipeline

```
User answers 4 questions (Claude Haiku)
        ↓
Knowledge graph lookup (psychology principles JSON — fitness / productivity / learning)
        ↓
Confidence scoring (constraint_fit × 0.4 + similar_case_success × 0.4 + motivation_sentiment × 0.2)
        ↓
Plan synthesis (Claude Sonnet — structured JSON output)
        ↓
Supabase persistence → results page
```

## Synthetic evaluation

The `/evaluation` page runs 9 synthetic personas (3 difficulty tiers per category) through the full pipeline and scores each generated plan on 5 metrics:

| Metric | Description |
|---|---|
| Personalization (1–10) | Keyword match between plan text and persona constraints |
| Principle Coverage (0–1) | Fraction of available psychology principles referenced |
| Confidence Score (0–1) | Weighted formula output |
| Confidence Label | Very High / High / Medium / Low / Very Low |
| Difficulty Appropriate | Plan's first minute reference ≤ persona's daily limit |

## Local setup

```bash
npm install
```

Create `.env.local`:

```
ANTHROPIC_API_KEY=sk-...
NEXT_PUBLIC_SUPABASE_URL=https://...supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
SUPABASE_SERVICE_ROLE_KEY=eyJ...
```

```bash
npm run dev        # http://localhost:3000
npm test           # unit tests (Jest)
npx tsc --noEmit   # type check
```

## Project structure

```
app/
  onboard/        conversational onboarding wizard
  results/        plan display with confidence meter + principle badges
  dashboard/      gamification dashboard
  evaluation/     synthetic evaluation tool
  api/            REST API routes
lib/
  ai/             embeddings, semantic search, knowledge graph, confidence, LLM
  gamification/   XP, levels, badge logic (pure functions)
  knowledge/      psychology principles JSON (fitness, productivity, learning)
  success-cases/  75 success case JSON + embeddings
components/
  results/        ConfidenceMeter, PrincipleBadges
  dashboard/      DailyCheckin, XPBar, StreakCounter, BadgeGrid, ProgressChart
  evaluation/     PersonaCard, MetricsTable
evaluation/
  personas.ts     9 synthetic test personas
  scoring.ts      5 scoring functions
  __tests__/      unit tests for scoring functions
```
